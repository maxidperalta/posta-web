# bankai-web

Sitio público de [Bankai](https://github.com/maxidperalta/bankai), marketplace de
servicios a domicilio para Argentina.

Un solo archivo HTML sin dependencias ni build. Se publica solo con GitHub Pages
en cada push a `main`.

**En vivo:** https://maxidperalta.github.io/bankai-web/

## Ver en local

```bash
npx serve .
```

## De dónde sale

Este repo es un espejo de `apps/web/` del repo principal (privado). Los cambios
se hacen allá y se copian acá — el sitio es público, el código de la app no.
